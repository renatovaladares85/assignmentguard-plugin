# Changelog

## 0.1.0 - 2026-09-29

Primeira versão pública.

- MVP preventivo para substituição inequívoca de grupo responsável antes das regras nativas do Ticket.
- Política standalone e providers declarativos para Behaviors 2.7.8 e Escalade 2.9.18–2.9.22.
- Configuração via `Config`, logging JSON Lines e decisões fail-safe/fail-open.
- Matriz de CI para GLPI 10.0.20–10.0.26, MySQL 5.7 e MariaDB 10.2.
- Gates de Composer, lint PHP 7.4, PHP-CS-Fixer e PHPStan.
- Documentação operacional, metadados públicos e licença `GPL-3.0-or-later`.
